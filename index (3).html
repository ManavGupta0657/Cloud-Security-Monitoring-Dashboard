What's inside
Everything a SOC dashboard needs
Live threat counter
Active threat count auto-refreshes every 4 seconds, simulating a real-time GuardDuty feed with severity breakdown.
24-hour event timeline
Stacked bar chart showing Critical, High, Medium and Low events across every hour of the day.
Attack type breakdown
Donut chart categorising threats — unauthorized access, DDoS, malware, data exfiltration, and other.
Filterable incident log
Filterable table of security events with real GuardDuty finding types, timestamps, and investigation status badges.
Network anomaly detection
Line chart of inbound traffic vs baseline — highlights the simulated DDoS spike at 3.4× normal volume.
Multi-region health
Uptime bars for 5 AWS regions with incident counters — US East, EU West, AP South, US West, SA East.
IAM compliance scanner
Policy audit scores for MFA, least privilege, root key usage and password policy — switchable by account scope.
Dark mode support
Automatically adapts to your system theme via CSS prefers-color-scheme. Works on every panel.
Fully responsive
CSS Grid layout adapts cleanly to mobile, tablet, and desktop screen sizes without any framework.
Tech stack
Three languages, one project
⬡
HTML · CSS · JavaScript
Frontend dashboard. Chart.js for charts, Tabler Icons for UI. No framework — pure vanilla.
🐍
Python · Flask · boto3
REST API backend. Connects to AWS GuardDuty, CloudWatch, IAM Access Analyzer via boto3.
⚙
C++ · g++17
High-performance threat detection engine. Sliding-window Z-score anomaly detection on log streams.
☁
AWS GuardDuty
Source of real threat findings. Finding types in the incident log are based on real GuardDuty events.
📊
AWS CloudWatch
CPU, network and Lambda error metrics. Used by the Python backend for real infrastructure data.
📄
GitHub Pages
Free static hosting. Auto-deploys on every push to main. No server needed for the frontend.
