How the Z-score detector works
Z = |value − μ| / σ
Each new log entry's inbound traffic (GB/h) is fed into a sliding window of the last 60 samples. The engine computes the rolling mean (μ) and standard deviation (σ). If the Z-score exceeds threshold = 3.0, the entry is flagged as anomalous. Root access, brute-force login counts, and port scans further escalate severity independently of the Z-score.
Compile & run commands
# step 1 — compile g++ -std=c++17 -O2 \ -o threat_engine \ threat_engine.cpp # step 2 — run (simulation mode) ./threat_engine \ --simulate \ --threshold 3.0 \ --window 60 \ --output threats_output.json # step 3 — Flask reads it curl localhost:5000/api/engine
